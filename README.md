# Zed Compact

Provides syntax highlighting and use of the Compact Language Server for the [Zed](https://zed.dev) editor.

## Install

The latest version should be available in the Zed Extensions Gallery. You can launch the gallery by pressing `Ctrl-Shift-X`, opening the command palette and selecting `zed: extensions`, or by selecting "Zed > Extensions" from the menu bar.

## Manually install on Zed

If you cannot find the `Compact` extension by searching it, you can manually install it with the following steps:
1. Clone this repo with `git clone https://github.com/midnightntwrk/compact-zed.git`
2. Launch the Zed Extension Gallery, by pressing `Ctrl-Shift-X`, opening the command palette and selecting `zed: extensions`, or by selecting "Zed > Extensions" from the menu bar.
3. Click on the `Install Dev Extensions` button at the top right corner, and select the folder where you just cloned repo.

After a few seconds, Zed will compile the extension and leave it installed ready to use.
